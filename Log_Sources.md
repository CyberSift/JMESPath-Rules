# Log Sources Available 

When adding a new JSON file for JMESPath detection rules for a new log source, refer to the table below to determine the relevant key to specify in the type field of each rule. If the log source you're looking for is not supported, please reach out to request support.


| Key | Label | Description |
|-----|-------|-------------|
| `WEBMARSHAL` | WebMarshal | WebMarshal Parser |
| `MAILMARSHAL` | MailMarshal | MailMarshal Parser |
| `IPA_LDAP` | IPA LDAP | IPA LDAP Parser |
| `MS_DNS_MULTILINE` | Microsoft DNS Multiline | Microsoft DNS Multiline Parser |
| `ORACLE_EXTENDED_XML` | Oracle Extended XML | Oracle Extended XML Parser |
| `ORACLE_OBP_WEB` | Oracle OBP WEB | Oracle OBP Web Parser |
| `APACHE_LOGS` | Apache Logs | Apache Logs (CLF) |
| `NGINX_LOGS` | Nginx Logs | NGINX Logs combined + POST REQUEST BODY) |
| `CLAMAV` | ClamAV | Use with ClamAV logs |
| `GITLAB` | GitLab | Use with GitLab logs |
| `EAC` | Exchange Admin Center | Use with Exchange Admin Center |
| `PLEASANTPASSWORDSERVER` | Pleasant Password Server | Use with Pleasant Password Server logs |
| `SWIFT_U2A_APP` | SWIFT U2A App | SWIFT U2A App |
| `SWIFT_SIL` | SWIFT SIL Logs | SWIFT SIL   |
| `SWIFT_AGI` | SWIFT AGI Logs | SWIFT AGI   |
| `GOOGLE_WORKSPACE` | Google Workspace Logs | Google Workspace Logs |
| `AWS` | AWS Cloudtrail Logs | AWS Cloudtrail Logs |
| `TRAEFIK` | Traefik Access Logs | Traefik Access Logs |
| `AZURE_EVENT_HUB` | Azure Event Hub | Azure Event Hub |
| `F5_LOADBALANCER` | F5 LoadBalancer | F5 LoadBalancer Logs |
| `DUO` | DUO   | DUO MFA Logs |
